# TUNA Routing Builder 2.3.1

## Один EXE для Windows x64

Готовая программа: `dist/TunaRoutingBuilder-v2.3.1.exe`. Можно скопировать только
этот файл на другой ПК; установка Python и папка `_vendor` не требуются.
Запускайте двойным щелчком. Первое открытие может занять несколько секунд.
В EXE-версии GEO-кэш сохраняется в `%LOCALAPPDATA%\TunaRoutingBuilder\geo-cache`,
а проекты сохраняются через диалог выбора файла. Для загрузки GEO нужен интернет.
EXE не имеет цифровой подписи издателя; Windows может показать предупреждение.

Сборка: изолированное окружение `.build-env`, `requirements.txt` и
`pyinstaller==6.16.0`, затем `build-exe.ps1`.
Проверены 34 теста и запуск собранного EXE из отдельной папки: реальные виджеты,
ресурсы интерфейса, экспорт/импорт TUNA, DoH без bootstrap IP и путь GEO-кэша.

## Полный редактор

Вкладка **Правила** содержит «Напрямую», «Через VPN» и «Блокировать» с отдельными
полями сайтов и IP: по одному правилу на строку. Поддерживаются domain:, full:,
keyword:, regexp: (переносимое подмножество), geosite:, IPv4/IPv6, CIDR, geoip:.
В **DNS** задаются два независимых списка: напрямую и через VPN, до 8 DNS в каждом.
Для каждого списка доступны «Авто» (выбор быстрого стабильного DNS в клиенте)
и «Приоритет» (порядок списка). Кнопки ↑/↓ меняют порядок, × удаляет DNS.
Поддерживаются DoH / UDP / TCP и DoT (только extended, не Xray), bootstrap IP
и hosts в виде `host.example = 192.0.2.1`. Общий тайм-аут запроса — 1000–10000 мс,
по умолчанию 5000 мс. Резервирование не должно выходить за пределы своего списка:
DNS через VPN не переключается на прямой DNS. Сам редактор DNS-запросы не тестирует.
Для новых возможностей требуется обновлённая Android TUNA с поддержкой DNS-пулов.
Happ-экспорт расширенных настроек блокируется, чтобы не терять параметры.
В **GEO / профиль** задаются название, маршрут по умолчанию, приоритет групп,
DomainStrategy и HTTPS URL GeoIP/GeoSite DAT. Встроены источники Android:
runetfreedom, v2fly, roscomvpn, loyalsoldier. Выбор источника подставляет URL и
запускает загрузку. «Скачать / открыть GEO-кэш» использует локальные DAT,
«Обновить GEO из сети» скачивает заново. Кэш находится в geo-cache рядом с программой.
При неудачном обновлении предыдущий исправный файл не заменяется.

В правилах доступны выпадающие подсказки (также Ctrl+Space). Введите geo или geosite:
для категорий выбранной базы. Стрелки выбирают подсказку, Enter/Tab вставляют,
Escape закрывает. Категории извлекаются из реальных DAT; без первой загрузки
доступны только подсказки синтаксиса. Категории разных URL не смешиваются.

Справа доступны полный TUNA-профиль, Happ-ссылка, Base64, JSON и прежний экспорт
только приложений. Happ не содержит приложений: интерфейс предупреждает об этом.
Флажок активации выбирает `happ://routing/onadd/` или `happ://routing/add/`.
Импорт принимает эти форматы; есть отдельная кнопка вставки из буфера.
Ошибка импорта сохраняет текущий профиль. По умолчанию импорт дополняет правила
без точных повторов и сохраняет приложения. DNS и основные параметры берутся
из импортированного профиля. Снятие «Дополнить» заменяет профиль целиком.
Принимается также HTTP(S)-ссылка на файл Happ/JSON/Base64/TUNA (до 350 КБ),
но не HTML-редактор и не произвольные форматы сторонних клиентов.
Если импорт содержит оба GEO URL, после применения запускается загрузка баз.
Приложения, уже добавленные пользователем, сохраняют названия и источники при слиянии.

«Сохранить проект» сохраняет настройки, приложения, названия и исходные ссылки/пути.
«Открыть проект» восстанавливает их без скачивания APK. Учитывайте сохранённые пути
при передаче проекта другим людям. Для пустого списка приложений полный профиль
экспортируется без секции apps. Ошибки/незавершённые проверки приложений блокируют
полный TUNA-экспорт и сохранение проекта.

Контракт: `tuna://routing/v1?data=<Base64url без padding>`, UTF-8 JSON
`{"version":1,"policy":{…},"apps":{"mode":"bypass","packages":[…]}}`.
Apps необязателен; иначе 1–100 уникальных package name, режим bypass или vpn.
Необязательный корневой `dns` содержит `remoteServers`/`domesticServers`,
`remoteSelectionMode`/`domesticSelectionMode` (`auto` либо `priority`) и `timeoutMs`.
Элемент списка: `transport`, `endpoint`, необязательный `bootstrapIp`, `route`
(`VPN` для remote и `DIRECT` для domestic). Старые одиночные DNS-ссылки совместимы.
При дополнении профиля без нового `dns` прежние расширенные настройки сохраняются.
До 500 правил суммарно, 256 КиБ декодированного документа. Policy — Happ-объект;
для UDP/TCP используются RemoteDns/DomesticDns, для DoH — RemoteDNSDomain/DomesticDNSDomain.
Нужна TUNA с поддержкой routing/v1. Поведение применения определяется Android-клиентом;
правила из подписки в актуальном клиенте применяются автоматически.

При полном TUNA-экспорте FakeDNS/UseChunkFiles автоматически выключаются,
а неизвестные Happ-поля исключаются из экспортируемой копии с уведомлением.
Исходный проект не изменяется; Happ сохраняет эти поля с предупреждением.
Кнопка в профиле удаляет неизвестные поля. GEO-правила требуют проверенных баз
на телефоне. GUI и локальные тесты не доказывают применение маршрутов на устройстве.

Проверки: `python -m unittest test_core test_policy test_geo test_routing_sources test_dns_pools -v`,
`python gui_smoke.py`, `python test_paste_gui.py`, `python gui_policy_smoke.py`,
`python gui_geo_smoke.py`, `python test_dns_gui.py`.

## Приложения и запуск

Версия 1.1: интерфейс CustomTkinter, отдельные карточки приложений и форма источника.
Приложение для Windows на Python 3.10+ с Tkinter. Библиотеки уже включены в `_vendor`;
эта папка должна оставаться рядом с `app.py`. Android SDK и ADB не нужны.
Запуск: **start.cmd** двойным щелчком. Он использует установленный Python либо
имеющийся на этом ПК Python из Codex. На другом ПК установите Python с Tcl/Tk.
Также можно выполнить `python app.py`.

1. Нажмите «+ Добавить». Каждый пункт добавляется отдельно.
2. Выберите источник: «Ссылка» (Google Play / RuStore / прямой APK) или «APK на ПК».
   При желании укажите собственное название. Для файла нажмите «Выбрать…».
3. Нажмите «Добавить приложение». Источник проверяется в фоне; результат появится
   в отдельной карточке. Источник и название можно изменить, пункт — удалить.
2. Выберите «Без VPN» (исключения) или «Через VPN» (только эти приложения).
3. Проверьте package name в таблице, удалите лишние записи.
4. Скопируйте ссылку или сохраните её в TXT.

Примеры входных ссылок:

- `https://play.google.com/store/apps/details?id=com.android.chrome`
- `https://www.rustore.ru/catalog/app/org.telegram.messenger`
- Прямой HTTP(S)-адрес APK; расширение .apk необязательно.
- Локальный APK через источник «APK на ПК» и кнопку выбора файла.

Пример результата:

`tuna://app-exclusions/v1?mode=bypass&packages=com.android.chrome,org.telegram.messenger`

Совместимо с TUNA 1.1.46-test2 и реализацией этого формата. Ссылка автоматически
выбирает режим, включает фильтрацию и ДОПОЛНЯЕТ его список, а не заменяет его.
Существующий VPN требуется переподключить. Без VPN значит прямой трафик приложения.
APK не проверяется на безопасность и не устанавливается; читается только package
из AndroidManifest.xml. Из магазина извлекается ID из адреса: существование
страницы и соответствие опубликованному APK не проверяются.

Список до 100 пунктов. Повтор package name отмечается ошибкой; удалите повторный
пункт или измените источник. Копирование заблокировано, пока есть ошибки или
незавершённые проверки — неполная ссылка не выдаётся за готовую.
Отсутствие приложения на телефоне не мешает сгенерировать ссылку.

Ограничения загрузки: APK до 512 МиБ, манифест до 8 МиБ, таймаут сети 15 секунд,
общая проверка времени загрузки 3 минуты, перенаправления ограничены. Проверка
сертификатов HTTPS включена; переход HTTPS → HTTP запрещён. Временный APK удаляется
после обработки. Отмена проверяется между блоками чтения; сеть может задержать
её до таймаута. При закрытии окно ждёт завершения отмены и удаления временного APK.
При принудительном завершении процесса временный файл может остаться.
Источники не отправляются сторонним сервисам;
для прямого APK запрос идёт на указанный сервер и его перенаправления.

Не поддерживаются: XAPK/APKS/AAB, страницы с кнопкой скачивания вместо прямого
файла, авторизация/cookies, старые числовые RuStore URL без package name.
В таких случаях используйте обычную страницу магазина или локальный APK.
TXT сохраняет результат выбранного экспорта. Для дальнейшего редактирования сохраняйте проект.

Проверки: `python -m unittest -v`, `python gui_smoke.py`.
Зависимости и их лицензии находятся в `_vendor`. При установке из исходников
без этой папки: `python -m pip install -r requirements.txt`.
