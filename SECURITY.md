# Безопасность

Поддерживаемая публичная линия на момент публикации: **1.5**. SLA исправлений и независимого security-аудита нет.

Если GitHub показывает кнопку **Report a vulnerability** на вкладке Security, используйте приватное сообщение сопровождающему. Если приватный канал недоступен, откройте issue только с просьбой предоставить канал, без эксплуатации, ключей и личных данных.

Для отчёта достаточно версии, протокола, ожидаемого/фактического поведения и воспроизведения на синтетическом профиле. Не публикуйте subscription URL, UUID, private key, PSK, пароли, cookies, полный QR, внутренние IP и идентификаторы устройств. Даже экспорт диагностики проверьте вручную.

## Границы доверия

- Подписка может автоматически менять DNS, маршруты и списки приложений. Доверие поставщику подписки — отдельное решение от доверия APK.
- Browser DoH, пользовательский Xray JSON и исключённые из VPN приложения имеют собственные пути DNS/трафика.
- Не отключайте TLS-проверку сертификата для устранения сетевой ошибки.
- APK 1.5 сохраняет исторический Android Debug сертификат; это компромисс совместимости, а не production key management. Не импортируйте чужую подпись или keystore в сборку.
- EXE не подписан Authenticode. Скачивайте только согласованный Release и сверяйте SHA-256; контрольная сумма с той же страницы не заменяет независимую подпись издателя.
- Native/Go-зависимости имеют отдельный цикл исправлений. Зафиксированная версия обеспечивает контролируемое обновление, но не гарантирует отсутствие уязвимостей.
