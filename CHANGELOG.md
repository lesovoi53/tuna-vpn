# Изменения

## 1.6 — 18 октября 2026

- Mieru обновлён до 3.38.1.
- MTU VPN: 1280–65535, ручной ввод, ползунок и быстрые значения. Применяется при следующем подключении; внутренний MTU AWG/WireGuard не переписывается.
- Исправлен показ профиля после импорта `.conf`/ZIP; расширенные параметры AWG сохранены.
- На заставке отображается TUNA; устранены повторные расшифровки настроек, задерживавшие подключение.
- CoreReceiver закрыт для сторонних приложений. Проверка APK включает SHA-256, криптографическую подпись/lineage, package и версию; FileProvider сужен. Автообновление остаётся отключённым.
- Строковые значения DataStore защищены AES-256-GCM с ключом Android Keystore и атомарной миграцией. Runtime-конфиги имеют отдельный жизненный цикл; это не шифрование всех файлов приложения.
- Для публичных конфигураций требуется HTTPS, HTTP разрешён только локальным адресам. Глобальная платформенная cleartext-политика пока сохраняется ради совместимости; issue #3 не объявляется полностью устранённым.
- TUN-адреса выбираются случайно при создании интерфейса с проверкой конфликтов подсетей.
- Настройки аварийного DNS и bootstrap согласованы с фактически используемыми ядрами; добавлены в Routing Builder 2.4.
- 892 JVM-теста: 0 ошибок, 0 пропусков. На планшете выполнено 54 сетевых прогона на разных MTU: 53 успешных, один первоначальный тайм-аут NaiveProxy, оба повтора успешны.

[Состав, подпись и границы проверки выпуска](docs/releases/1.6-public.md).

## 1.5 — первый публичный снимок

- Единая публикация Android-клиента и TUNA Routing Builder 2.3.1 с исходниками, документацией и лицензиями.
- Номер Android-версии: `1.5`, versionCode `26101602`; пакет и прежняя подпись сохранены для обновления установленной линии.
- Включено текущее состояние разработки: клиентские DNS-пулы, импорт VLESS с нативной проверкой, автоматические правила подписки, URL-test, ограниченное хранение диагностики и управление блокировкой сна.
- Speedtest не предлагается как пользовательский режим. Поставка ограничена перечисленными в компонентном манифесте ядрами.
- Разделены проверенные результаты, старые наблюдения и непроверенные сценарии; см. [отчёт выпуска](docs/releases/1.5.md).

Это описание состава первого публичного снимка, а не утверждение, что все изменения реализованы именно между двумя публичными тегами. Старые закрытые рабочие сборки не превращаются задним числом в публичные релизы.
