# Известные ограничения

- APK 1.5 сохраняет прежний debug-сертификат ради обновления. Dedicated production signing и отдельный новый applicationId не введены.
- Готовый APK только ARM64. Наличие ABI в Gradle не доказывает, что для него собраны все ядра.
- Полная чистая native-пересборка на новом runner и побитовая воспроизводимость HEV/qWDTT/Cronet не подтверждены. Доступные исходники и их происхождение документированы.
- Полный пользовательский Xray JSON сам задаёт маршруты/DNS. Browser DoH и приложения вне VPN не обязаны использовать DNS клиента. IPLeak показывает выход рекурсивного резолвера, который не обязан совпадать с введённым anycast IP.
- Обычный routing path выбирает Xray; DoT из расширенного редактора не обещается этому пути.
- Протокол, присутствующий в исходниках ядра, может отсутствовать в UI или не иметь принятой end-to-end конфигурации. Серверная поддержка также необходима.
- URL-test — проверка доступности/задержки к определённой цели, не измерение общей скорости и не гарантия работы всех сайтов. Старые TCP-сессии при смене сервера могут оборваться.
- Android может задерживать периодические проверки во сне. Постоянная блокировка сна увеличивает расход; не включайте её без причины.
- Нативный лог/экспорт может содержать чувствительные сведения. Ограничение размера не заменяет предварительную проверку перед отправкой.
- EXE неподписан, не содержит VPN-движок и не проверяет доступность введённого частного DNS. Геоданные зависят от внешних источников и их условий.
- Обновление доверенной подписки может повторно активировать её правила. Это предусмотренное автоматическое применение, а не необязательный просмотр.
- Для 1.5 не повторяется полный многочасовой device/energy тест только из-за смены версии. Новые публичные результаты не заменяются частными историческими наблюдениями.
