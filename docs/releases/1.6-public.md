# TUNA VPN 1.6 / Routing Builder 2.4

Android: **1.6 / 26101808**, ARM64, Android 8.0+. Windows: однофайловый **Routing Builder 2.4**.

## Изменения

- Mieru 3.38.1; MTU VPN 1280–65535 с ручным вводом, ползунком и быстрыми значениями.
- Исправлены показ импортированных AWG/.conf/ZIP-профилей, логотип заставки TUNA и задержка подключения из-за повторных операций с зашифрованными настройками.
- Закрыт внешний доступ к CoreReceiver; реализованы проверки APK и ограничен FileProvider.
- Строковые настройки DataStore шифруются AES-256-GCM через Android Keystore с миграцией данных.
- Случайные TUN-адреса с учётом конфликтов; аварийный DNS и bootstrap доступны в Android и Builder.

## Установка и подпись

Скачайте APK вручную и установите поверх существующего приложения. Автообновление пока отключено. Package `app.tunaturn.android.debug` сохранён, APK не debuggable. Android 13+ использует новый production-сертификат с signing lineage; Android 8–12 сохраняет прежний signer. Проверена цепочка обновлений от 1.5 на физическом планшете API 36 без очистки данных. EXE не подписан Authenticode.

## Проверки и границы

892 JVM-теста: 0 ошибок, 0 пропусков; release build/lint, R8 и native-хеши прошли. Builder: 45 unit-тестов, GUI и frozen self-test прошли. На планшете выполнено 54 сетевых прогона с MTU 1280/1500/9000/32768/65535: 53 успешных; один первоначальный HTTPS-тайм-аут NaiveProxy не повторился в двух повторных проверках. Проверены VLESS с CF/CDN, два Snell-профиля, Mieru, NaiveProxy, qWDTT, MasterDNS и AWG.

Нет проверки всех протоколов без рабочих профилей, длительной нагрузки/сна, максимальных UDP-датаграмм, установки на старых Android и чистой сборки на новом runner. MTU 65535 не означает передачу таких пакетов по интернету. Глобальная cleartext-политика сохранена ради совместимости; HTTPS обязателен для публичных конфигураций. Runtime plaintext, WebView cookies и явный экспорт профилей не объявляются зашифрованными новым DataStore wrapper.
