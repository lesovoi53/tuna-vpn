# TUNA VPN 1.65.2-rc1 — предварительная сборка

Android versionCode `26102010`, ABI `arm64-v8a`, minSdk 26.
Стабильным выпуском остаётся 1.65.1.

Кандидат добавляет обработку `has_ipv6=false` в профилях TrustTunnel,
включая TLV-ссылки для HTTPS и QUIC. Для трафика, направленного в этот туннель,
домены разрешаются только в IPv4, а явные IPv6-адреса отклоняются ядром.
Параметр сохраняется при редактировании профиля.

Захват IPv6 интерфейсом VPN сохранён. Пользовательские правила DIRECT и
приложения, исключённые из VPN, по-прежнему работают напрямую: это не глобальное
отключение IPv6 устройства.
