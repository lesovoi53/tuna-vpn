# TUNA VPN 1.65.1

20 октября 2026. Android versionCode `26102009`, ABI `arm64-v8a`, minSdk 26.
Routing Builder 2.4 не изменён.

## Исправление

На Honor MagicOS 10 ядра не могли повторно открыть конфигурацию через memfd:
`/proc/self/fd/3: permission denied`. Это нарушало запуск VPN и проверки импорта.
Передача конфигураций ядрам и HEV возвращена к временным файлам приложения
с правами 0600 в отдельных закрытых каталогах сессий. DNS-группы принимают
обычные файлы только текущего владельца без доступа для группы и остальных.

Все остальные возможности 1.65 сохранены: DNS-группы, выбор резолверов,
маршрутизация, импорт профилей, HTTPS-политика и шифрование DataStore.
Пакет и цепочка подписи сохранены; устанавливайте APK поверх существующей
версии без удаления данных.

## Изменение гарантии безопасности

Runtime-конфигурации с секретами временно находятся на диске незашифрованными.
Они удаляются после остановки читателей; незавершённые сессии очищаются
при следующем запуске. Прежняя гарантия отсутствия таких файлов на диске
и соответствующая полнота исправления issue #3 больше не действуют.
Подробности: [модель защиты](../security/issue-3-memory-runtime.md).
