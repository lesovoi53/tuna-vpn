# TUNA VPN 1.65

Дата: 20 октября 2026. Android versionCode `26102008`, ABI `arm64-v8a`,
minSdk 26, application ID `app.tunaturn.android.debug`, release без отладки.
Routing Builder 2.4 распространяется без изменений.

## Изменения

Выпуск объединяет кандидаты 1.6.1-rc1–rc8: защищённую передачу runtime-конфигов
ядрам, HTTPS-политику управляющих URL, исправления AWG/VLESS-импорта,
подбор DNS-резолверов и самостоятельные именованные группы DNS-серверов.
Подробности — в [changelog](../../CHANGELOG.md),
[руководстве резолверов](../user/masterdns-resolvers.md) и
[модели защиты runtime-конфигов](../security/issue-3-memory-runtime.md).

Группа содержит 2–8 серверов одной подписки либо собственные серверы.
Маршрутизация берётся из подписки, если задана, иначе из приложения.
Каждое новое соединение получает одного участника; существующие потоки
не переносятся между серверами. Один поток не получает сумму их скоростей.

## Проверки

Окончательная 1.65: release/lint, 1006 JVM-тестов без ошибок и пропусков,
44 модели / 25 полей R8, native allowlist и хеши, подпись API 26/28/32/33/36
прошли. APK установлен поверх rc8 без uninstall/clear data; SHA-256 извлечённого
установленного APK совпал. В повторной memfd-проверке полный обход 157 файлов
(317322872 байта) не обнаружил synthetic canary или запрещённых runtime-файлов;
повторное чтение/закрытие успешно, VPN выключен до и после. Тестовый helper удалён.
Routing Builder 2.4: 34 unit-теста и отдельные DNS/clipboard GUI-проверки прошли;
EXE совпадает по SHA-256 с выпуском 1.6.

Сводка окончательного артефакта публикуется в `validation.json`, контрольные суммы —
в `SHA256SUMS.txt`. Подпись сохраняет согласованную ротацию API 33 и совместимость
старого signer для API 26–32. Закрытые ключи в исходники не входят.

Кандидат rc8 прошёл 1006 JVM-тестов без ошибок и пропусков, release/lint,
R8 и проверку native-манифестов. Он установлен обновлением без очистки данных;
на планшете проверены создание двух групп, выбор/сохранение резолверов,
переключение на исходные списки подписки и обратно, готовность 2/2 и 4/4 участников.

На том же кандидате в приложении Speedtest выполнены последовательные измерения
шести одиночных серверов и двух групп, Single/Multi, выбранные/подписочные адреса,
с одним тестовым сервером. Завершён 31 из 32 сценариев. Один Multi с выбранным
набором завершился ошибкой и не восстановился при переподключении.
Два контрольных сценария групп прошли после одной повторной попытки.
Частные профили, адреса, ключи, скриншоты и журналы устройства не публикуются.

Наблюдавшийся максимум группы из четырёх серверов — 15,8 Мбит/с download,
против 13,1 у лучшего одиночного участника с выбранными резолверами.
На исходных адресах та же группа дала 14,4 Мбит/с. Это отдельные наблюдения,
не обещание скорости: серии последовательны, сеть меняется, Single зависит
от участника. Некоторые выбранные наборы ухудшили upload или устойчивость.

## Ограничения

- Встроенное короткое сравнение измеряет download; оно не гарантирует
  лучший upload и длительную устойчивость. Исходный список всегда сохраняется.
- Полная Speedtest-серия выполнена на rc8, а не повторена на финальной 1.65.
  Изменения финализации — версия и документация; проверки финального APK
  перечислены отдельно в `validation.json`.
- Нет нового полного native build на чистом runner, длительной проверки сна/
  энергопотребления, смены Wi-Fi на мобильную сеть или физического обновления
  на Android 8–12. Непроверенные серверные реализации не объявляются совместимыми.
- Защита конфигураций в памяти не защищает от root и чтения памяти процесса.
  Явный экспорт пользователя может содержать секреты.
- Автообновление отключено. APK устанавливается поверх существующего приложения
  без uninstall/clear data. EXE Routing Builder не имеет Authenticode-подписи.
