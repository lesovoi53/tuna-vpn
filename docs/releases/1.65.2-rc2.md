# 1.65.2-rc2 — кандидат, 23 октября 2026

Android versionCode: `26102301`. Локальный кандидат; публикация отдельно.

- Единственный доступный интерфейс — Orbit. Старое сохранённое предпочтение
  остаётся совместимым с резервными копиями, но переключатель убран.
- «Оформление и язык» открывает соответствующие настройки. Сетевые настройки
  доступны через общие настройки. Редактор маршрутизации наследует общую тему;
  подробности применённых DNS свёрнуты в отдельную секцию.
- Карточка DNS-группы показывает участников и резолверы снимка запущенной
  сессии. Выбранная группа не выдаётся за работающую. Ядро сообщает суммарную
  готовность, поэтому индивидуальный статус участников не придумывается.
- URL-test показывает причину сохранения текущего сервера или переключения:
  порог улучшения, подтверждения и удержание. На главной отображается сервер
  запущенной сессии. Алгоритм выбора и настройки пользователя сохранены.
- Пункт «Цепочка прокси» убран из меню профиля. Сохранённые цепочки продолжают
  работать; сами настройки и их формат не удалены.
- Меню экспорта отдельного профиля позволяет копировать/отправлять исходную
  ссылку протокола либо полный профиль TUNA. Для неподдерживаемого представления
  показывается причина; экспорт файлом и массовый экспорт сохранены.
- Повреждённая сжатая ссылка экспорта получает отдельное объяснение при импорте.
  Проверка целостности не ослаблена; автоматического угадывания ключей нет.

Частные восстановленные ссылки, адреса подписок и профили не входят в исходники.
Для восстановления повреждённых записей подписки нужно заменить их на исправные
ссылки у источника; обновление APK не меняет содержимое сервера подписок.

## Проверка локального кандидата

- Полный последовательный прогон: 1015 синтетических тестов и одна временная
  частная проверка восстановления, 0 ошибок и пропусков. Частная проверка вынесена
  за пределы публичного дерева после выполнения. В первом параллельном прогоне
  существующий тест отмены HTTPS не уложился во временной порог; при повторном
  прогоне без одновременной оптимизации APK прошёл без изменения теста.
- `lintRelease`, `assembleRelease`, проверка публичного дерева прошли.
- Подпись проверена для API 26, 28, 32, 33 и 36. Обновление поверх 1.65.1
  установлено на MagicPad3 с сохранением данных.
- На планшете проверены оформление/язык, маршрутизация, меню экспорта, импортный
  предпросмотр двух восстановленных ссылок. Временная группа из двух европейских
  серверов одной подписки показала готовность 2/2, трафик и выходной IP; обе карточки
  показывают применённые локальные резолверы. Временная группа удалена, исходный
  выбранный профиль восстановлен, VPN выключен.
- Сценарий URL-test 719/433 мс проверен синтетически, живой повтор Snell не выполнен.
  Проверка группы не является новым сравнительным замером скорости.
