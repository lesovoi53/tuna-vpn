## Изменения

- Раздельные remote/domestic emergency DNS: `system`, `resolver`, `disabled`;
  bootstrap наследуется при отсутствии поля либо задаётся как `system` или
  ручной TCP resolver с literal IP и DIRECT. Значение system по умолчанию
  относится к DNS подписки; локальные настройки не переписываются автоматически.
- Системный DNS связан с underlying Android network; ограничены ожидание и
  жизненный цикл bridge. Системный аварийный DNS выходит напрямую, что отражено
  в интерфейсе. Частный DoH без pin сохраняет обычную TLS-проверку.
- Настройки String/StringSet зашифрованы AES-GCM через AndroidKeyStore с атомарной
  миграцией и отказом без сброса данных при ошибке ключа. Ограничены runtime
  файлы с секретами и перенос HTTP credentials через redirect.
- Проверка обновления учитывает реальный APK, доверенную подпись и lineage;
  управление VPN извне ограничено. Автообновление намеренно остаётся выключенным
  через `PRIVATE_DISTRIBUTION=true`.
- Заставка Android 12+/compat и логотип первого приветственного экрана используют
  существующую графику TUNA. Размеры и расположение welcome-экрана сохранены.

Полные границы: [DNS-контракт](../development/routing-contract.md),
[хранение секретов](../development/secret-storage.md). Общий experimental
sing-box router явно отвергает терминальный emergency `system`/`resolver` и
предлагает Xray; отсутствие emergency и `disabled` поддерживаются. Это
ограничение не относится к отдельному system bootstrap транспортного ядра.

## Физический планшет API 36

Цепочка обновлений `1.5 → 26101801 → 26101802 → 26101803 → 26101804 → 26101805` прошла
без uninstall/clear data. На первом переходе с миграцией сверены все 61
контрольные суммы логических настроек, сохранён UID `10247`, подтверждены
шифрование Preferences и сохранность vault. Эти 61 сравнение не объявляются
повторёнными на каждом следующем переходе.

На кандидате `26101804` установка обновлением прошла. Холодный запуск
зафиксирован снимком экрана: отображается рыба TUNA. Первый welcome-экран
проверен по ресурсам; отдельный запуск onboarding с очисткой данных не выполнялся.

Установка `26101805` выполнена через `install -r`; package ID, versionCode и
SHA-256 установленного APK совпали с итоговым артефактом. Холодный запуск занял

## Исправление задержки подключения

В прежнем кандидате пользователь наблюдал индикатор подключения около 39 секунд.
Контрольный запуск с диагностикой и проверенным package/SHA занял 21,713 с:
17,9 с пришлись на повторное чтение/сохранение зашифрованных Preferences,
а bridge, компиляция конфигурации и запуск native-процесса — около 19 мс.
Кратковременный ранний libxray был отдельной проверкой конфигурации; он не доказывает
падение или перезапуск рабочего router.

В `26101805` кеш хранит два проверенных снимка и использует структурное сравнение.
Целевой набор: 11 тестов PASS; no-op decrypt-вызовы 77 → 7, чередование снимков
140 → 0. Tamper и отказ без сброса данных покрыты тестами. На устройстве Snell
подключился за 1,155 с, UI показал подключение. Это конкретный замер на данном
планшете и сети, не обещание одинаковой задержки на всех устройствах. Временные
startup traces удалены из итогового production-кода.

## Оставшиеся границы

Полная матрица 6/2 и 8+8 resolver через TUN, отказ/восстановление всех групп,
смена сети и sleep/resume не проверены. Приведённые DNS smoke-тесты и успешный
refresh не заменяют эту матрицу.

Очистка завершена: удалены только `qa-startup-timings.txt` и
`qa-security-continuity.json`, оба результата подтверждены; удалены три
вспомогательных test package, проверка их отсутствия прошла. Исходный профиль
Naive выбран, VPN оставлен отключённым; активных VPN-сервисов не обнаружено.
Публичное дерево: 870 файлов PASS. SDK-проверка подписи прошла для API
26/28/32/33/36; физический планшет по-прежнему только API 36.

Не выполнены физическая установка на API 26–32, длительный энерготест,
полная приёмка в мобильной сети, чистая пересборка на новом runner и запуск
Builder на другом чистом Windows ПК. WebView cookies и явный профильный экспорт
не объявляются зашифрованными новым Preferences wrapper. Производственные
серверы не изменялись; публикация и автоматическая загрузка обновления не проверялись.
EXE не имеет Authenticode-подписи.
