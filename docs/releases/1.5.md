# Выпуск TUNA VPN 1.5

Android versionName **1.5**, versionCode **26101602**, Android 8.0+, ARM64. В тот же выпуск включён **TUNA Routing Builder 2.3.1** для Windows. Бинарники и SHA-256 находятся в [Release v1.5](https://github.com/lesovoi53/tuna-vpn/releases/tag/v1.5).

## Состав

- Android-клиент, локальные адаптеры и native overlays, закреплённые upstream-источники.
- Генератор `tuna://routing/v1`: приложения, правила, DNS и GEO, импорт поддерживаемых TUNA/Happ форматов.
- Пользовательская и developer-документация, лицензии, тесты, инструкции сборки/подписи.
- Чистый публичный снимок без личных профилей и старой закрытой Git-истории.

## Подпись и ограничения

Package ID `app.tunaturn.android.debug`; сам APK **не debuggable**, но сертификат — прежний Android Debug. Это сделано для совместимости обновления, а не является новым production signing setup. [Инструкция проверки](../development/release.md).

Новая установка APK 1.5 поверх приложения на физическом планшете, полный многочасовой энерготест, мобильная сеть и чистая native-сборка на новом runner **в публикационной проверке не выполнялись**. Результаты старых частных испытаний не выдаются за новую приёмку этой версии. EXE не подписан Authenticode.
