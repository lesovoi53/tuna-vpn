# TUNA VPN 1.6 / 26101807 — Mieru и MTU

Локальная доработка кандидата 26101805. Публикация не выполняется.

## Изменения

- Mieru 3.37.0 → стабильный 3.38.1, commit
  `a2208ee7a38fb41d843a13ecdde858e67ef2f485`.
  Сохранены обязательная локальная SOCKS-аутентификация и явный отказ `05 ff`.
  Upstream-тесты не заменены нашими; проверяются оба набора.
- Настройки → MTU VPN: целые значения 1280–65535, ползунок на весь диапазон,
  ручной ввод и быстрые варианты 1280, 1380, 1400, 1420, 1500, 9000, 16384,
  32768, 49152, 65535. По умолчанию 1280.
- Сохранение MTU не прерывает соединение. Новое значение применяется при
  следующем подключении. Android TUN и HEV используют один снимок значения;
  переключение SOCKS-цели на существующем TUN сохраняет его исходный MTU.
- Протокольные MTU WireGuard/AWG, Mieru и KCP не переписываются.

[Доказательства предела MTU](../development/tun-mtu.md). Верхняя граница —
предел представления пакета и интерфейса, не рекомендация для скорости.

## Физический планшет, Android API 36

Установка обновлением: 26101805 → 26101806 → 26101807, без удаления данных.
Перед первым обновлением сняты хеши 61 записи; сразу после установки 26101806
все совпали, UID и зашифрованное хранилище сохранены. Последующие переключения
профилей и MTU выполнялись для теста; совпадение всех исходных записей после
этих пользовательских действий не заявляется.

Независимый probe имеет отдельные UID и сертификат. Он подтвердил реальную
VPN-сеть и MTU через Android LinkProperties. HTTPS — GET фиксированного
тестового ресурса 262144 байта, обычная TLS-проверка, HTTP 200, стабильная сеть.

| Итоговый APK 26101807 | MTU | DNS | HTTPS |
| --- | ---: | --- | --- |
| Mieru 3.38.1 | 1280 | 4/4 на промежуточном 26101806 с тем же native-кодом | 262144 байта, HTTP 200 |
| Mieru 3.38.1 | 1500 | 4/4 | 262144 байта, HTTP 200 |
| Mieru 3.38.1 | 9000 | 4/4 | 262144 байта, HTTP 200 |
| Mieru 3.38.1 | 65535 | 4/4 | 262144 байта, HTTP 200 |
| Snell / sing-box-extended | 65535 | 4/4 | 262144 байта, HTTP 200 |
| Naive / sing-box-extended, восстановленный профиль | 1280 | отдельно не повторялся | 262144 байта, HTTP 200 |

Проверены ручной ввод 9000, запрет сохранения 65536, быстрый выбор 1500 и 65535,
полоса быстрых значений в верхней части диапазона и край ползунка 65535.
После сохранения 1500 при активном VPN фактический MTU остался 1280;
после переподключения стал 1500. Максимум сохранился после полного перезапуска
приложения и использовался последующим подключением Snell.

Итоговое состояние: исходный профиль выбран, MTU 1280, VPN выключен.
Три временных test package и контрольный файл удалены; рабочие профили,
подписки, сетевые настройки устройства и серверы не удалялись/не менялись.

что по интернету отправлялись IP-пакеты по 65535 байт, и не доказывает ускорение.
HEV не обновлялся. Routing Builder не менялся в этой фазе. Публикация не выполнена.
