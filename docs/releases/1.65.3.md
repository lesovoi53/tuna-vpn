# 1.65.3

Стабильный выпуск: version name `1.65.3`, versionCode
`26102401`, ARM64, Android 8.0+. Tag: `v1.65.3`.

## Исправления

1. Остановка группы отменяет отложенное повторное подключение: группа не запускается снова после нажатия «Остановить».
2. После смены SOCKS-порта или учётных данных Xray VPN получает новый адрес подключения, включая перезапуск ядра с временно недоступным SOCKS.
3. TUN-дескриптор, созданный после отмены запуска или остановки службы, закрывается и не публикуется как активный интерфейс.
4. Общий тайм-аут и отмена обновления подписки распространяются на активное HTTP-соединение после перенаправления.
5. Профили подписки без исходного ID получают устойчивую идентичность; для однозначно совпадающего подключения сохраняются локальные настройки при переименовании или изменении параметров.
6. Текстовый файл с корректными ссылками `tuna://`, `wireturn://` и `wt://` импортируется через декодер полного профиля.
7. Повторяющиеся домены MasterDnsVPN, в том числе различающиеся только регистром, отклоняются до создания конфигурации ядра. Экран резолверов также защищён от дубликатов в ранее сохранённом профиле.
8. IPv6-резолверы MasterDnsVPN приводятся к единому формату адреса и порта; адрес в квадратных скобках без порта больше не теряется при запуске.
9. Обычный режим MasterDnsVPN сохраняет разные порты одного DNS-адреса, как сканирование и персональные наборы доменов.
10. Trojan с gRPC `authority` импортируется с сохранением параметра и его передачей в Xray.

## Улучшения из 1.65.3-rc1

- Отдельные карточки, сканирование, результаты и выбор резолверов для каждого
  домена MasterDnsVPN. Можно проверить все домены последовательно.
- Локальные наборы видны в профиле и сохраняются при обновлении подписки.
  Ядро получает только выбранные пары домен–резолвер.
- Исправлено периодическое падение при открытии экрана резолверов во время загрузки профиля.
- Вместо тестов скорости и сравнения наборов экран предлагает выбрать адреса,
  прошедшие проверку совместимости с конкретным доменом.
- Сохранена поддержка нескольких доменов одного сервера; исправлено распределение
  пакетов при одной копии в стратегии Round Robin. Значения по умолчанию не меняются.

## Совместимость обновления

Устанавливайте APK поверх существующего приложения без удаления данных.
Пакет `app.tunaturn.android.debug`, minSdk 26 и политика ротации подписи сохраняются:
Android 8–12 используют прежний сертификат, Android 13+ — production-сертификат
с цепочкой ротации. Routing Builder остаётся версии 2.4.

Исправление профилей без исходного ID действует при новом импорте и последующих
обновлениях подписки. Ранее созданные случайные ID нельзя достоверно восстановить;
клиент не угадывает соответствие старых записей. Если после обновления остаётся старая
запись, сначала проверьте новую запись и перенесите нужные личные настройки.
Профили с явным серверным ID продолжают использовать этот ID.
