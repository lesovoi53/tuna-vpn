# 1.65.3-rc1 — предварительный выпуск

Публикуется тот же APK, который проверен на планшете: внутреннее имя
`1.65.3-dns-test3`, versionCode `26102305`, ARM64, Android 8.0+.
Название GitHub-пререлиза отличается от внутреннего имени APK намеренно:
проверенный артефакт не пересобирался ради переименования.

## Изменения

- Исправлено периодическое падение экрана DNS-резолверов при загрузке профиля:
  список доменов и конфигурация теперь берутся из одного снимка состояния.
- Каждый домен MasterDnsVPN имеет отдельную карточку, сканирование базы,
  результаты и выбор рабочих резолверов. Можно проверить все домены последовательно.
- Локальные наборы сохраняются отдельно для каждого домена при обновлении подписки;
  выбранные адреса отображаются в редакторе и сведениях о соединении.
- Нативное ядро получает точные пары домен–резолвер, без добавления перекрёстных пар.
- Удалены измерение скорости загрузкой и сравнение наборов с экрана резолверов.
  Проверка совместимости туннеля, полезной нагрузки DNS и повторные пробы сохранены.
- Исправлено распределение при одной копии пакета в стратегии Round Robin.
  Режим и значения по умолчанию клиентских профилей не изменены.

## Проверки

- 1033 JVM-теста, 0 ошибок, 0 пропусков; `lintRelease` и `assembleRelease` прошли.
  Lint: 0 ошибок, 251 предупреждение.
- Подпись проверена для API 26, 28, 32, 33 и 36. Сохранены пакет
  `app.tunaturn.android.debug`, minSdk 26 и существующая цепочка ротации.
- Обновление поверх предыдущей тестовой сборки установлено на планшете без очистки данных.
- Падение воспроизведено в прежней сборке на четвёртом открытии. После исправления
  выполнены пять открытий с наблюдением по 20 секунд и 60 секунд сканирования;
  новых записей о падении процесса нет. Все четыре домена отображаются.
- Проверена совместимость синтетических серверных экспортов с декодером TUNA:
  отдельные StormDNS-ссылки и один TUNA-профиль с несколькими доменами.
- Нативные изменения MasterDNS собраны и проверены целевыми тестами до сборки APK.

## Границы проверки

Полное завершение сканирования всей базы после исправления не подтверждено:
оно оставлено работать на планшете. Проверка на телефоне пользователем ещё не
подтверждена. Новый полный прогон всех протоколов, длительного сна, расхода батареи
и сборка native на чистом CI-окружении не выполнялись. Рост скорости от нескольких
доменов не гарантируется и устойчивого общего прироста в проведённых замерах не доказано.

Устанавливайте поверх существующей версии без удаления данных. Routing Builder 2.4
приложен без изменений. Этот выпуск не обновляет серверное меню X-Manager Lite.
