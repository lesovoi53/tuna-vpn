# TUNA Routing Builder 2.3.1

Routing Builder — отдельный редактор для Windows x64. Он создаёт профиль маршрутизации для TUNA: правила сайтов и IP, параметры DNS и список приложений. Редактор не предоставляет VPN-сервер и не проверяет прохождение трафика на телефоне.

## Запуск

Если в выпуске опубликован `TunaRoutingBuilder-v2.3.1.exe`, скачайте его, проверьте контрольную сумму и запустите. Самостоятельному EXE не нужны Python и папка `_vendor`; первое открытие может занять несколько секунд. EXE не имеет подписи издателя, поэтому Windows может показать предупреждение.

Для запуска из исходников нужны Python 3.10+ с Tcl/Tk и зависимости из `requirements.txt`. Установите зависимости в отдельное окружение и запустите `python app.py` из каталога редактора. Наличие `_vendor` и локального вспомогательного Python зависит от поставки: не рассчитывайте на окружение компьютера разработчика.

## Создание профиля

1. На вкладке правил заполните группы «Напрямую», «Через VPN» и «Блокировать». У каждой группы отдельные поля сайтов и IP; одно условие на строку.
2. В «GEO / профиль» задайте имя, маршрут по умолчанию, порядок групп и DomainStrategy. При пересечении условий порядок влияет на результат.
3. Для GEO-правил выберите источник или HTTPS URL файлов DAT и загрузите базы. Категории появляются из фактического содержимого выбранных баз.
4. В DNS настройте прямой список и список через VPN. В каждом допускается 1–8 серверов; «Авто» и «Приоритет» выбирают режим работы клиента.
5. При необходимости добавьте приложения и выберите «Без VPN» либо «Через VPN». Дождитесь проверки всех карточек.
6. Скопируйте полный TUNA-профиль или сохраните выбранный экспорт в TXT. Перенесите ссылку в импорт TUNA, проверьте применённые настройки и переподключитесь после изменения фильтрации приложений.

Поддерживаются `domain:`, `full:`, `keyword:`, `regexp:` переносимого подмножества, `geosite:`, IPv4/IPv6, CIDR и `geoip:`. Например, `domain:example.com` — доменное условие. Регулярные выражения с lookaround и обратными ссылками не входят в переносимое подмножество. Всего разрешено до 500 правил.

Подсказки доступны при вводе и по Ctrl+Space. Стрелки выбирают вариант, Enter/Tab вставляют, Escape закрывает. До загрузки баз доступны подсказки синтаксиса, а не полный набор GEO-категорий.

## DNS и совместимость

UDP/TCP задаются IP-адресом с необязательным портом, DoH — HTTPS URL. Bootstrap IP необязателен для DoH. DoT использует `tls://` без пути и требует Bootstrap IP при доменном имени. Hosts задаётся строками вида `host.example.com = 192.0.2.1`; этот адрес предназначен для примера, а не для реального подключения.

DNS-тайм-аут — 1000–10000 мс, исходное значение 5000 мс. Порядок меняется кнопками ↑/↓. Резервирование не должно переходить из группы VPN в прямую группу. Редактор не выполняет проверку DNS-запросов.

DoT доступен в формате для extended, но не поддерживается Xray. Текущий общий путь маршрутизации Android использует Xray: для него экспортируйте DoH, UDP или TCP. Не считайте сохранение документа в Builder подтверждением совместимости с выбранным ядром телефона.

## Приложения

Кнопка «+ Добавить» принимает страницу магазина с package name, прямую ссылку на APK или APK на компьютере. Можно задать собственное название карточки. Из адреса магазина извлекается package name; редактор не доказывает существование страницы или соответствие опубликованному APK. Для APK читается манифест, приложение не устанавливается и не проверяется на безопасность.

Лимит — 100 уникальных package name. Ошибки и незавершённые проверки блокируют полный TUNA-экспорт и сохранение проекта. Пустой список исключает секцию `apps` из полного профиля. Отсутствие приложения на телефоне не препятствует подготовке ссылки.

XAPK/APKS/AAB, страницы с кнопкой скачивания вместо APK и загрузки с обязательной авторизацией не поддерживаются. Для APK установлены ограничения 512 МиБ, манифеста 8 МиБ и времени загрузки. HTTPS-сертификаты проверяются; понижение перенаправления с HTTPS до HTTP запрещено. Локальный APK не отправляется на сервис анализа; сетевой источник скачивается с указанного адреса и допустимых перенаправлений.

## Импорт и проекты

Импорт принимает полный TUNA-профиль, совместимые Happ-ссылки, JSON/Base64 и HTTP(S)-адрес текстового файла этих форматов. Загружаемый файл ограничен 350000 байтами. HTML-редактор или страница авторизации не являются файлом правил.

По умолчанию «Дополнить» объединяет правила без точных повторов, сохраняет приложения, а основные параметры и DNS берёт из импортируемого документа. Если нового расширенного `dns` нет, сохраняются прежние расширенные настройки. Разные режимы приложений не объединяются: отключите «Дополнить» только если нужна полная замена. Ошибка импорта сохраняет текущий профиль.

«Сохранить проект» сохраняет редактируемые настройки, названия приложений и исходные ссылки/пути. «Открыть проект» восстанавливает проект без повторной загрузки APK. Проект может раскрывать локальные пути или персональные URL: проверяйте его перед передачей. TXT содержит результат выбранного экспорта и не заменяет проект.

В EXE-поставке GEO-кэш расположен в `%LOCALAPPDATA%\TunaRoutingBuilder\geo-cache`; при запуске из исходников используется локальный `geo-cache`. Обновление требует интернета. Неудачное обновление не должно заменять предыдущую исправную базу. Категории разных URL не смешиваются.

## Форматы экспорта

Полный профиль переносит правила, DNS и приложения. Happ-экспорт не содержит приложений; расширенные DNS-настройки блокируют такой экспорт, чтобы параметры не потерялись. Флажок активации выбирает `happ://routing/onadd/` или `happ://routing/add/`.

Старый экспорт приложений:

```text
tuna://app-exclusions/v1?mode=bypass&packages=com.example.client
```

Он дополняет список выбранного режима в Android и включает фильтрацию. `bypass` означает выбранные приложения напрямую, `vpn` — только выбранные приложения через VPN.

При полном TUNA-экспорте FakeDNS и UseChunkFiles выключаются, а неизвестные Happ-поля исключаются из экспортируемой копии с уведомлением. Исходный проект при этом сохраняет свои данные. Проверьте уведомление до переноса в клиент.

## Контракт routing/v1

```text
tuna://routing/v1?data=<base64url>
```

`data` — канонический Base64url без `=` padding, полученный из JSON в UTF-8. URI не содержит fragment или дополнительных query-параметров. Android ограничивает ссылку 350000 символами, декодированный документ — 256 КиБ. JSON не допускает повторяющихся полей; корневые поля — только `version`, `policy`, необязательные `apps` и `dns`. `version` — число `1`.

Структура без конкретных DNS-серверов ниже поясняет поля, а не служит готовой конфигурацией:

```text
{
  "version": 1,
  "policy": { ... проверенный Happ-объект ... },
  "apps": { "mode": "bypass", "packages": ["com.example.client"] },
  "dns": { ... расширенные DNS-настройки ... }
}
```

`apps`, если присутствует, содержит только `mode` (`bypass` или `vpn`) и `packages` — 1–100 уникальных Android package name. Пустой список передавайте отсутствием `apps`.

`policy` содержит Happ-поля `Name`, `GlobalProxy`, `RouteOrder`, `DomainStrategy`, группы `BlockSites`, `ProxySites`, `DirectSites`, `BlockIp`, `ProxyIp`, `DirectIp` и совместимые DNS/GEO-настройки. Для UDP/TCP применяются `RemoteDns`/`DomesticDns`, для DoH — `RemoteDNSDomain`/`DomesticDNSDomain` с соответствующим `DNSType`. Регистр имён полей важен. Готовый валидный объект формирует редактор.

Расширенный `dns` поддерживает:

| Поле | Значение |
| --- | --- |
| `remoteServers`, `domesticServers` | Списки 1–8 резолверов через VPN и напрямую |
| `remoteSelectionMode`, `domesticSelectionMode` | `auto` или `priority` |
| `timeoutMs` | Целое число 1000–10000 |
| `hosts` | Соответствия имени и IP |
| `queryStrategy` | `UseIP`, `UseIPv4` или `UseIPv6` |
| `disableCache` | Логическое значение |

Элемент списка содержит `transport` (`DOH`, `DOT`, `UDP`, `TCP`), `endpoint`, необязательный `bootstrapIp` и `route`. Для `remoteServers` маршрут строго `VPN`, для `domesticServers` строго `DIRECT`. Если DNS одновременно присутствует в корневом `dns` и `policy.TunaDNS`, значения должны совпадать.

Правила из подписки применяются клиентом автоматически при успешном импорте или обновлении; локальные изменения правил сохраняются. Результат экспорта, проверка формата и локальные тесты редактора не заменяют проверку маршрутов и исключений на Android.
