# Подписки и обновления

Подписка — адрес, по которому клиент получает набор подключений и, если поставщик добавил их, параметры маршрутизации. URL может быть персональным ключом доступа. Не публикуйте его в issue, снимках экрана или журналах.

## Добавление

Добавьте URL в разделе подписок, дождитесь загрузки и проверьте список импортированных профилей. Сообщение о пропущенных записях означает, что часть содержимого не стала доступными подключениями; изучите причины и при необходимости запросите совместимый формат у поставщика.

Поддерживаются списки совместимых ссылок, в том числе в Base64, и поддерживаемые структурированные документы. Произвольный JSON другого VPN-клиента не обязательно совместим. Импорт маршрутов поддерживает TUNA routing/v1 и совместимые Happ-правила, в том числе переданные подпиской.

## Категории профилей по названию

Для категорий используются **имена отдельных серверов**, а не название всей подписки. Правила одинаковы для импортированных и вручную добавленных профилей. В обычной URI-ссылке имя передаётся после `#` с URL-кодированием; в структурированной подписке — в поле имени профиля.

### CDN в разделе Обход БС

Для обычного VPN-профиля добавьте в имя фразу `обход бс`: например, `Москва обход бс` или `CDN — Обход БС`.

- Фраза распознаётся в любой части имени, без учёта регистра.
- Между словами допускаются несколько пробелов и неразрывный пробел. Вариант `обход-бс` с дефисом вместо пробела не подходит.
- Профиль переносится в **Обход БС → CDN**, сохраняя исходный протокол — VLESS, Snell и т. д.
- Одного слова `CDN` или фактического размещения сервера за CDN недостаточно: для сортировки нужны слова `обход бс` в имени.
- qWDTT, MasterDnsVPN / StormDNS и WebDAV и так относятся к «Обход БС» по типу подключения; они остаются в своих подразделах, а не становятся CDN-профилями.

Размещение в «Обход БС» имеет значение для групп: в версии 1.5 групповой URL-test для этой категории недоступен. Не помечайте так обычные VPN-серверы только ради оформления списка.

### Cloudflare в подразделе VLESS CF

Для **VLESS** добавьте отдельную метку `CF` латинскими буквами: `Германия CF`, `CF Польша`, `Москва [cf]`, `CF-сервер`. Профиль будет показан в **VPN → VLESS CF**.

Метка не должна примыкать к буквам, цифрам или `_`. Поэтому `CF1`, `1CF`, `mycf`, `my_cf`, `CFМосква` и `_CF_` не подходят. Слово `Cloudflare` и кириллические `КФ` / `сф` тоже не являются меткой. Регистр латинских букв значения не имеет.

Этот подраздел выделяет только VLESS. Например, `Trojan CF` без фразы `обход бс` остаётся в **VPN → Trojan**. Наличие метки не проверяет принадлежность сервера Cloudflare и не меняет транспорт, Host, TLS/SNI или адрес подключения.

### Приоритет и примеры

| Тип профиля | Имя | Раздел и подраздел |
| --- | --- | --- |
| VLESS | `Москва обход БС` | Обход БС → CDN |
| Snell | `Москва обход бс` | Обход БС → CDN |
| VLESS | `Германия [CF]` | VPN → VLESS CF |
| VLESS | `Москва обход БС [CF]` | Обход БС → CDN — фраза `обход бс` имеет приоритет |
| VLESS | `Германия CDN` | VPN → VLESS — метки `обход бс` нет |
| VLESS | `Германия Cloudflare` | VPN → VLESS — отдельной метки `CF` нет |
| Trojan | `Германия CF` | VPN → Trojan — подраздел VLESS CF только для VLESS |
| qWDTT | `Москва` | Обход БС → qWDTT — определяется типом |

После переименования размещение пересчитывается; параметры самого соединения не меняются. Избранные профили могут отображаться в отдельном верхнем блоке, а полные Xray-конфигурации с балансировщиком закрепляются отдельно от обычной сортировки.

## Правила из подписки

При добавлении и обновлении клиент может автоматически включить предоставленные правила и исключения приложений без отдельного диалога согласия. Добавляйте подписки только от поставщика, которому доверяете выбор прямых и VPN-маршрутов.

Личные правила и переключатели правил подписки хранятся отдельно от удалённого документа. Личные правила имеют приоритет перед правилами источника; повторное обновление сохраняет локальные изменения. Сброс переключателей правил источника не равен удалению собственных правил.

Проверьте источник маршрутизации и настройку использования правил подписки. Успешное обновление с правилами источника снова включает их использование; локальные переключатели отдельных правил и собственные правила сохраняются. Не путайте отключение отдельного правила с отключением всей маршрутизации. После изменения списка приложений переподключите VPN.

## Обновление

В настройках подписки можно включить автообновление, задать интервал, обновлять только выбранную подписку и требовать туннель для обновления. Если требуется туннель, а он не работает, это может препятствовать загрузке; проверяйте выбранный режим до изменения адреса подписки.

Автообновление зависит от сети и фоновых ограничений Android. Для немедленной проверки выполните ручное обновление. Сверяйте время успешного обновления и сообщения об ошибках: начало загрузки не означает успешного применения.

Показатели использованного трафика, лимита и рекомендованного профиля зависят от данных поставщика. Они не заменяют его личный кабинет. После изменения профиля результаты прежнего URL-теста могут исчезнуть: измерение связано с прежней конфигурацией.
