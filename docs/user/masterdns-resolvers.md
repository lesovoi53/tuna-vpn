# DNS-резолверы для MasterDnsVPN

Экран «DNS-резолверы» помогает подобрать резолверы для конкретного профиля MasterDnsVPN в выбранной Wi-Fi или мобильной сети. Проверка использует домены и параметры туннеля этого профиля. Результаты для другого сервера или другой сети могут отличаться.

Откройте «Серверы», найдите профиль в группе «DNS-туннель» и выберите «DNS-резолверы» в его меню действий. Экран также доступен из редактора сохранённого профиля, если в нём нет несохранённых изменений.

## База адресов

Нажмите «Скачать базу» или «Обновить базу». Приложение загружает два публичных списка по HTTPS:

- [Trickest resolvers](https://github.com/trickest/resolvers), файл `resolvers.txt`.
- [MassDNS resolvers](https://github.com/blechschmidt/massdns), файл `lists/resolvers.txt`.

База содержит кандидатов для проверки. Наличие адреса в списке само по себе не подтверждает совместимость с вашим DNS-туннелем. Загрузка запускается кнопкой; сохранённая база доступна офлайн при следующем открытии экрана.

В карточке базы показаны число уникальных адресов, время обновления и состояние источников. Если удалось получить только часть источников или в списке были неверные строки, приложение показывает частичное обновление. При полном отказе загрузки прежняя база сохраняется.

Для своей базы нажмите «Импорт TXT». Импорт заменяет текущую базу кандидатов. Используйте UTF-8, по одному IP-адресу на строку. Поддерживаются IPv4, IPv6 и необязательный порт; без порта используется `53`. Для IPv6 с портом нужны квадратные скобки. Пример с документационными адресами:

```text
# Замените примеры своими адресами
192.0.2.1
192.0.2.2:5353
2001:db8::1
[2001:db8::2]:5353
```

Пустые строки и комментарии после `#` пропускаются, одинаковые адреса объединяются. Доменные имена, URL и неверные адреса не принимаются; число пропущенных строк показывается в состоянии источника. Пределы базы — 8 МиБ входных данных и 100 000 уникальных адресов. Если файл не содержит допустимых адресов или превышает пределы, прежняя база сохраняется. Сохраните исходный TXT отдельно, если нужен перенос базы на другое устройство.

## Проверка профиля и сети

1. Выберите профиль MasterDnsVPN в верхней части экрана.
2. Выберите сеть для проверки. Мобильная сеть появляется, когда Android предоставляет её приложению.
3. Нажмите «Сканировать базу» и дождитесь завершения.
4. Откройте «Результаты последней проверки».

Пакеты проверки привязаны к выбранной физической сети Android. Само сканирование не переключает текущее VPN-подключение. При смене сети или параметров профиля текущая проверка останавливается.

Большая база проходит два этапа. Сначала быстрые DNS-запросы к домену туннеля помогают выбрать кандидатов для подробной проверки. Затем до 128 адресов проверяются нативным ядром MasterDnsVPN: оно проверяет туннель, измеряет доступную полезную нагрузку DNS вверх и вниз и выполняет повторные туннельные пробы. Небольшой список сразу переходит к подробной проверке. Адреса, которые не попали во второй этап, не считаются проверенными на совместимость.

В результатах видны резолвер, домен профиля, задержка, потери повторных проб и MTU вверх/вниз. Здесь MTU означает размер полезной нагрузки DNS, а не MTU интерфейса VPN. Задержка относится к успешным повторным туннельным пробам, а не ко времени всего сканирования. Сначала показаны успешные и предварительно рекомендованные адреса; далее учитываются потери и задержка.

Проверку можно остановить кнопкой «Остановить». При ручной остановке текущие результаты нельзя применить. Если общий срок проверки истёк, но отдельные адреса уже прошли все пять туннельных проб, приложение показывает частичный результат и позволяет выбрать эти адреса. Остальные адреса не считаются проверенными. Результаты сохраняются на 30 минут для той же сети и параметров профиля; при истечении срока или изменении сети/профиля потребуется новая проверка. Это срок пригодности измерений для выбора, а не срок действия уже сохранённого набора резолверов.

## Выбор и применение

Отметьте прошедшие проверку адреса или нажмите «Выбрать рекомендованные». Предварительная рекомендация учитывает полезную нагрузку вверх/вниз, потери и задержку; число адресов не ограничено тремя. Она исключает заметно слабые по MTU пути, которые могут уменьшить общий размер пакетов сессии. Это эвристика, а не измеренная скорость. Затем нажмите «Использовать выбранные». Набор сохраняется только для выбранного профиля; допустимо выбрать от 1 до 128 адресов.

Кнопка рекомендаций отмечает адреса, но ещё не применяет их к подключению. Счётчик выбора и кнопка «Использовать выбранные» закреплены внизу экрана и остаются видимыми при прокрутке результатов.

Сканер различает порты одного IP. Для подключения выбирайте один порт на каждый IP: штатный загрузчик рабочего режима MasterDnsVPN объединяет повторные IP и использует первый адрес.

В карточке «Какие резолверы использовать» доступны два источника:

- «Из профиля / подписки» — исходный список, который обновляется вместе с профилем.
- «Мой выбранный набор» — ваш отдельный список, который сохраняется при обновлении подписки.

В редакторе профиля блок «DNS-серверы подключения» показывает выбранный источник, количество и полный список адресов для подключения. Если используется личный набор, исходный список подписки свёрнут под кнопкой «Показать исходный список — сейчас не используется». Изменение исходного списка не заменяет личный набор.

Переключение источника требует явного применения. Исходный список подписки сохраняется, поэтому к нему можно вернуться. Если меняется активный подключённый профиль, кнопка предупреждает о переподключении VPN и применяет выбор с переподключением. Для неактивного профиля выбор используется при его следующем подключении.

Проверка и сохранённый выбор относятся к одному серверному профилю. Текущая версия не объединяет несколько VPS, не балансирует трафик между ними и не выполняет фоновое переключение серверов.

## Сравнение скорости наборов

После сканирования нажмите «Измерить и сравнить наборы». Приложение создаёт временные независимые клиентские сессии с аутентифицированным локальным SOCKS. DNS-пакеты идут через выбранную физическую сеть, HTTPS-проверка — через проверяемый туннель. Активный VPN и его профиль не переключаются.

Сравнивается до четырёх разных наборов: текущий выбранный набор из прошедших проверку адресов, лучший одиночный путь, промежуточный и полный предварительно рекомендованный набор. Для совпадения со штатным рабочим режимом каждый набор содержит не более одного порта на IP. Расширение прекращается, если следующий больший набор успешно измерен, но не даёт улучшения более 10%.

Для каждого набора выполняется одна HTTPS-загрузка до 256 КиБ с [официального download endpoint Cloudflare](https://github.com/cloudflare/speedtest). Проверка не использует прямой маршрут при ошибке туннеля, не следует HTTP-перенаправлениям и проверяет сертификат/имя HTTPS-сервера. Максимум — 1 МиБ полезных данных на сравнение; DNS-повторы и заголовки дают дополнительный трафик. Лимит учитываемых UDP-данных — 8 МиБ на набор, примерно 32 МиБ на четыре набора; уже находящиеся в сети пакеты и сетевые заголовки не дают гарантии точного тарифицируемого объёма. Одна попытка ограничена 3 минутами, всё сравнение — 13 минутами. На мобильной сети это расходует мобильный трафик.

Результат показывает полезные КиБ/с всего набора. Время считается от отправки HTTP-запроса и включает ожидание ответа; установление сессии и SOCKS/TLS в него не входят. В полезных байтах учитывается только тело ответа. Это короткое сравнение загрузки, не длительный замер канала и не измерение upload. По нему нельзя приписывать скорость отдельному резолверу. При разнице до 10% сохраняется предыдущий лучший набор. Показанные фактические параметры сессии получены после серверного согласования; сервер может ограничивать настройки.

Успешно завершённое сравнение сохраняется вместе со сканированием для профиля и сети; оно не продлевает исходные 30 минут. Смена режима, профиля или сети требует новой проверки. Отменённое сравнение не заменяет прежнюю рекомендацию. Кнопка «Остановить» всегда доступна снизу; уход с экрана закрывает временную сессию. Для применения результата отдельно нажмите «Использовать выбранные».

## Режим работы

В редакторе профиля выберите «Из профиля», «Скорость», «Баланс» или «Устойчивость». На экране DNS-резолверов есть переход к редактору. Изменения вступают в силу после сохранения профиля; сравнение использует сохранённый режим.

| Режим | Балансировка | Обычные копии | Копии установки потока |
| --- | --- | --- | --- |
| Из профиля | Исходная | Исходные | Исходные |
| Скорость | Потери, затем задержка (6) | 1 | 2 |
| Баланс | Потери, затем задержка (6) | 2 | 3 |
| Устойчивость | По кругу среди лучших по потерям (8) | 3 | 4 |

Это запрошенные параметры; сервер может уменьшить число копий. Режимы не меняют шифрование, MTU или ARQ-окна. При потерях дублирование иногда повышает полезную скорость, поэтому название «Скорость» не гарантирует лучший результат в каждой сети. Исходные поля профиля сохраняются, возврат к ним доступен в любой момент. Обновление подписки сохраняет личный режим, но сама подписка не может назначить его вместо пользователя. При явном экспорте личный режим передаётся расширением `tuna_performance_mode`.

Общие DNS-пулы маршрутизатора описаны отдельно в [«Маршрутизация и DNS»](routing-and-dns.md).

## Несколько VPN-серверов

В редакторе сохранённого DNS-профиля включите «Распределять новые соединения»,
выберите 2–8 участников и сохраните. Основной профиль всегда входит в состав.
Можно объединять серверы одной подписки либо только собственные серверы.
Разные подписки и собственные серверы с подпиской смешивать нельзя.

Маршрутизация берётся из подписки; если она не задана, используются настройки
приложения. Для собственных серверов используются настройки приложения.
Выбранные для каждого участника DNS-резолверы и режим работы сохраняются.

«По кругу» распределяет новые соединения последовательно, «Меньше активных
соединений» выбирает доступный сервер с меньшей текущей нагрузкой по числу
соединений. Открытый поток остаётся на своём сервере до закрытия; его скорость
не складывается из скоростей участников. Отказ сервера обрывает его открытые
потоки, а новые соединения могут использовать оставшихся участников.

Состав хранится только на устройстве и сохраняется при обновлении подписки.
Ссылка `stormdns://` не переносит локальную группу. Если участник удалён или
его конфигурация несовместима, исправьте состав перед запуском: приложение
не сокращает его автоматически. Дополнительные сессии повышают расход
батареи и служебного трафика. Число доступных серверов видно в статусе подключения.
