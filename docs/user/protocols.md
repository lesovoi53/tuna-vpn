# Протоколы и совместимость

Используйте протокол и параметры, выданные вашим сервером. Одно название протокола не гарантирует совместимость всех его версий, транспортов и расширений.

Основной пользовательский редактор содержит VLESS, Hysteria2, Snell, Mieru, Trojan, Shadowsocks, TUIC, AnyTLS, NaiveProxy, WireGuard, AmneziaWG и TrustTunnel. Отдельные формы предназначены для qWDTT, MasterDnsVPN / StormDNS и WebDAV. Последние требуют соответствующей серверной инфраструктуры; обычный WebDAV-сервер не становится сервером туннеля только из-за наличия доступа к файлам.

| Подключение | Что важно перенести из конфигурации сервера |
| --- | --- |
| VLESS | UUID, транспорт, TLS или REALITY, SNI, ключи и дополнительные параметры транспорта |
| Hysteria2 | Аутентификация, TLS/SNI, обфускация и порты; доступность UDP в сети |
| Snell | Ключ, версия и режим, параметры обфускации и передачи UDP |
| Mieru | Учётные данные, порт или диапазон, TCP/UDP и параметры профиля |
| Trojan | Пароль, TLS/SNI и транспорт |
| Shadowsocks | Метод шифрования, пароль и порт |
| TUIC | Учётные данные, TLS и параметры передачи UDP |
| AnyTLS | Пароль, TLS/SNI и настройки сессий при необходимости |
| NaiveProxy | Учётные данные, TLS и совместимые серверные параметры |
| WireGuard | Приватный ключ клиента, публичный ключ сервера, endpoint, адреса интерфейса и маршруты |
| AmneziaWG | Параметры WireGuard и согласованный с сервером набор параметров обфускации; не все расширения взаимозаменяемы |
| TrustTunnel | Адрес, учётные данные, TLS/SNI и параметры совместимого сервера |
| qWDTT | Параметры соответствующего обходного подключения |
| MasterDnsVPN / StormDNS | Домен и параметры DNS-туннеля, совместимый резолвер |
| WebDAV | Параметры совместимого WebDAV-туннеля |

В состав проекта входят разные нативные компоненты. Список возможностей нативного бинарника шире пользовательского интерфейса: наличие протокола в ядре, справочнике или исходниках не является обещанием готового импорта, редактора и работающего соединения в опубликованном APK. Для дополнительных типов и расширенных полей проверяйте примечания конкретного выпуска и сообщение проверки конфигурации.

Полный **Xray JSON** импортируется как отдельная конфигурация с собственными настройками DNS и маршрутизации. Это не обещание отдельного редактора для каждого протокола, который можно описать внутри JSON.

**CDN и CF — не отдельные VPN-протоколы.** Они обозначают подразделы списка: метка `обход бс` переносит VPN-профиль в «Обход БС → CDN», а отдельная латинская метка `CF` выделяет VLESS в «VPN → VLESS CF». [Правила названий](subscriptions.md#категории-профилей-по-названию).

При несовместимости не заменяйте протокол вручную, сохранив прежний пароль и адрес: запросите корректную конфигурацию сервера. Успешный URL-тест подтверждает конкретный запрос в текущей сети; он не доказывает работу UDP, всех сайтов, цепочек и длительных соединений.

## Свой сервер MasterDnsVPN / StormDNS

Серверная часть DNS-туннеля доступна в отдельном репозитории **[TUNA DNS Tunnel](https://github.com/lesovoi53/tuna-dns-tunnel)**. Там находятся установщик для Linux, инструкция делегирования DNS-зон, меню доменов и шифрования, настройка выхода Direct/SOCKS5 и редактор экспортируемых параметров клиента. X-Manager для установки не требуется; внешний SOCKS5-прокси при необходимости предоставляется отдельно.

После установки экспортируйте `stormdns://` для отдельной зоны или `tuna://` со всеми доменами одного сервера и импортируйте ссылку в приложение. Изменение ключа или шифрования на сервере требует обновить клиентский профиль. Изменение пресета экспорта применяется к новым ссылкам и не меняет существующие профили в приложении автоматически.

Исходный протокол и серверное ядро разработаны в [MasterDnsVPN](https://github.com/masterking32/MasterDnsVPN). TUNA DNS Tunnel добавляет серверную упаковку и управление. [Отличия и инструкция](https://github.com/lesovoi53/tuna-dns-tunnel#readme), [проверенные сценарии и ограничения](https://github.com/lesovoi53/tuna-dns-tunnel/blob/main/VALIDATION.md).
