# Установка и первое подключение

Для TUNA VPN 1.5 нужны Android 8.0 или новее, устройство arm64 и действующие параметры сервера. APK для arm64 не подходит для старых устройств только с 32-битным Android и для обычного x86-эмулятора.

## Установка и обновление

1. Скачайте APK из официального выпуска проекта и сравните его SHA-256 с контрольной суммой выпуска.
2. Разрешите установку APK для приложения, которым вы открываете файл, и установите TUNA.
3. При обновлении устанавливайте APK поверх имеющегося приложения. Не удаляйте приложение ради обновления: удаление может стереть сохранённые профили и настройки.

У текущей линии APK историческое имя пакета `app.tunaturn.android.debug` и debug-сертификат подписи. При этом release APK собирается с отключённым `debuggable`. Суффикс пакета, тип сертификата и возможность отладки — разные свойства. Для обновления с сохранением данных Android требует совместимый пакет и ту же подпись; самостоятельная сборка с другим ключом может не установиться поверх опубликованной. Это ограничение подписи не следует обходить удалением приложения без резервной копии.

## Добавление подключения

1. Получите у администратора ссылку профиля, файл конфигурации или URL подписки. Не публикуйте их: они могут содержать доступ к серверу.
2. Откройте добавление профиля. Используйте импорт подходящего формата либо создание вручную. URL подписки добавляйте как подписку, чтобы затем получать обновления.
3. После импорта проверьте название, тип подключения и сообщения о пропущенных или неподдерживаемых записях. Для ручного профиля перенесите адрес, порт, учётные данные и дополнительные поля без изменений.
4. Выберите нужный профиль и запустите подключение. При первом запуске разрешите создание VPN в системном диалоге Android.
5. Дождитесь статуса подключения и откройте нужный сайт или приложение. Отдельно проверьте приложения, для которых настроен прямой маршрут.

Android обычно допускает один активный VPN-сервис для одного пользователя: другое VPN-приложение может остановить TUNA или помешать подключению. Разрешение VPN не заменяет действующий серверный аккаунт.

## После подключения

Для сравнения доступности профилей используйте [URL-тест](diagnostics.md). Настройте [маршруты и DNS](routing-and-dns.md), если часть трафика должна идти напрямую. После изменения исключений приложений переподключите VPN. После других изменений также переподключитесь, если интерфейс сообщает, что они требуют перезапуска.

Перед удалением приложения, сбросом настроек или переходом на APK с другой подписью сохраните доступные экспорты профилей и исходные ссылки в защищённом месте. Не считайте экспорт одной ссылки полной резервной копией всех настроек приложения.
