# Руководство TUNA VPN 1.5

TUNA — Android-клиент для подключения к вашим VPN-серверам и совместимым туннелям. Приложение не выдаёт сервер, аккаунт или подписку: параметры подключения предоставляет администратор сервиса.

- [Маршрутизация, исключения приложений и DNS](routing-and-dns.md)

- [URL-тест, диагностика и частые вопросы](diagnostics.md)
- [TUNA Routing Builder 2.3.1](../routing-builder.md)

Публичный APK рассчитан на Android 8.0 и новее, архитектуру arm64. Название стабильной версии — 1.5. Совместимость конкретного сервера, сети, производителя телефона и фонового режима проверяется отдельно; название релиза не означает проверку всех сочетаний.
