# Следующая сборка после 1.6.1-rc7

Согласовано пользователем 20 октября 2026: перенос интерфейса групп выполнить
в следующей сборке, не пересобирать установленную rc7 ради этого изменения.
Макет показан и одобрен. Изменение входит в кандидат 1.6.1-rc8.

- Создание групп и все настройки групп разместить в разделе «DNS-туннель».
- В этом разделе показывать группы, их состав и режим распределения соединений.
- Убрать настройки группы из редактора отдельного DNS-сервера.
- Состав: серверы одной подписки либо только собственные серверы.
- Маршрутизация: правила подписки, если заданы; иначе правила приложения.
  Для собственных серверов — правила приложения.
- В приёмочных проверках FP-серверы тестировать вместе, остальные отдельно;
  это условие проверки, а не дополнительный фильтр состава в приложении.

Группы хранятся отдельно от профилей. Активная группа использует актуальные
конфигурации участников; одиночное подключение снимает выбор группы.
Старые локальные наборы rc7 мигрируют в именованные группы.

Для приёмки пользователь выбрал установленное приложение Speedtest на планшете:
на каждом одиночном сервере и каждой группе проверить режимы «Одинарное»
и «Множественное», используя один сервер измерения. Эти результаты не подменяются
временем DNS-ответа или краткой проверкой доступности HTTPS.
