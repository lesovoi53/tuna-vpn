Рабочая точка первого публичного снимка: Android 1.5, versionCode 26101602; Builder 2.3.1. Это новый публичный Git-корень, не история всех закрытых итераций. Исходники и тесты текущего состояния сохранены; приватные серверные/телефонные артефакты намеренно не перенесены.

Не делайте выводов о доступности протокола только из `go.mod` или имени класса. Проверяйте импорт → выбранное ядро → компилятор → нативную проверку → реальное подключение. Серверный отказ не равен отказу формата; успешный импорт не равен доступности сервера.
